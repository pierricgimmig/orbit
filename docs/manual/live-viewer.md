# Live viewer

The run book is the [quick start](index.md): install `orbit-service`, run `orbit-service --serve 44766`, open `http://127.0.0.1:44766/`, pick a process and press Record.

The [home page](../index.html) opens a saved capture. The [features page](../features.html) is the longer tour: scope search, call trees, live statistics, disassembly, the service’s own lanes, themes, the phone layout and Chrome traces.
