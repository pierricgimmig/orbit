Symbols and modules

Hooking needs a file offset. Sampling needs a virtual address. The UI needs a name. Those three numbers come from different parsers that all have to agree on load bias.

Object files

orbit_object_utils::CreateObjectFile (src/ObjectUtils/ObjectFile.cpp) dispatches on LLVM’s object-file kind:

  • ElfFile — ELF, DWARF, GNU build-id, .symtab / .dynsym, .gnu_debuglink, .eh_frame ranges
  • CoffFile — PE/COFF, export table, debug directory pointing at a PDB
  • PdbFile — PDB via LLVM (PdbFileLlvm) or Windows DIA (PdbFileDia)

ObjectFile explains load bias carefully: ELF symbols are relative to a virtual zero that is not always the first PT_LOAD; PE uses ImageBase. GetExecutableSegmentOffset is the in-memory offset of .text. For ELF that usually matches the file offset; for PE it often does not — which is why uprobes (file offset) and sampling (absolute VA) go through ModuleUtils/VirtualAndAbsoluteAddresses.h.

Fallback symbols: if DWARF/PDB is missing, LoadDynamicLinkingSymbolsAndUnwindRangesAsSymbols / LoadFallbackSymbolsFromFile still give the Functions tab something to hook (exports, dynsym). This fork’s README commit “Don’t discard symbols with no build-id” is about keeping those modules visible.

SymbolHelper and SymbolLoader

SymbolHelper searches, in order-ish: cache directory, user additional paths (--additional_symbol_paths), structured debug directories (/usr/lib/debug style), and — still — Stadia SDK paths:

GGP_SDK_PATH/sysroot/usr/lib/debug
// plus a parent-path heuristic tagged SymbolSource::kLocalStadiaSdk

SymbolLoader (owned by OrbitApp) is the async orchestrator:

  1. RetrieveModuleAndLoadSymbols tries real debug symbols.
  2. On failure, RetrieveModuleItselfAndLoadFallbackSymbols.
  3. Remote: download the file from the instance via DownloadFileFromInstance (SSH/SFTP), unless --disable_instance_symbols.
  4. Optional Microsoft symbol server (RemoteSymbolProvider/MicrosoftSymbolServerSymbolProvider) behind --symbol_store_support.
  5. --enable_unsafe_symbols allows a file whose build-id does not match.
  6. --auto_symbol_loading (default true) kicks this off as modules appear; the flag text warns that Orbit can go unresponsive.

ggpvlk.so is still prioritized first in the load queue (OrbitApp.cpp, kGgpVlkModulePathSubstring) so a Stadia Vulkan ICD gets symbols before the game — leftover, harmless if the module is absent.

Module list and updates

At capture start, TracerImpl::Startup reads /proc/<pid>/maps via ModuleUtils/ReadLinuxModules.h and emits ModulesSnapshot.

During capture, OpenMmapTask records executable and non-executable mmaps. ProcessMmapEventAndReturnTimestamp keeps only the target pid and timestamps after enable. UprobesUnwindingVisitor turns those into ModuleUpdateEvent and refreshes libunwindstack maps. Integration test ModuleUpdateOnDlopen covers the happy path (needs perf_event_paranoid ≤ 0 or root).

Windows uses Toolhelp ListModules, then ETW ListModulesEtw if that is empty.

Addresses: three numbers

NumberWho uses it
File offsetuprobe config2 / trampoline patch site
Virtual address in module (RVA / ELF st_value)symbol tables, Functions tab
Absolute address in the processsamples, mmap, stop-unwinding-at, Wine dispatcher

Conversion is SymbolVirtualAddressToAbsoluteAddress(addr, module_start, load_bias, executable_segment_offset). Getting any of those four wrong produces hooks that never fire or samples that never symbolize. The PE-in-anonymous-map case is the documented footgun: the file offset is in a r-- header map, the runtime VA is in an anonymous r-x map.

Source and disassembly

Once symbols include line info, CodeViewer / CodeReport / SyntaxHighlighter show source. Source path remapping is src/SourcePathsMapping. Disassembly uses Capstone (also used to size trampolines). This path was not exercised in this review.

Build-id is the join key. Cache files, instance downloads, and “is this the right PDB?” all go through build-id (or PE equivalent via WindowsBuildIdUtils). --enable_unsafe_symbols is the escape hatch and a good way to silently attribute samples to the wrong binary.
