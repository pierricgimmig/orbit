What to fix · what to add · why

Roadmap

Priorities follow the product that exists: a Linux collector driven by a Qt viewer, with dynamic timers as the differentiator. Items that only make a leftover Stadia path prettier are last.

P0 — fix the collector contract

Land a fast uprobe teardown

Merge the intent of PR #10: one tracefs registration per function, per-CPU fds as TRACEPOINT consumers, still close everything on stop. Keep the opt-in bench. Until this lands, kernel uprobes remain the “slower” method the UI apologizes for, and high-core machines punish Hook count at stop. Do not ship ParallelFor-on-close as the fix.

Capability probe at OrbitService start

Before any capture, log and expose: uprobe PMU present?, tracefs vs debugfs readable?, perf_event_paranoid, effective RLIMIT_NOFILE, cgroup v1/v2, user-space instrumentation available (arch + lib present). Surface this in the connection dialog. Fail uprobe_type() as an error event, not an exception.

Read tracefs first

GetTracepointId: try /sys/kernel/tracing/events/... then debugfs. Same for any future uprobe_events writer. This is a small patch that restores sched/GPU on distros that never mount debugfs for unprivileged users (the service is root, but some environments only have tracefs).

P1 — make tests tell the truth

  • Document a privileged job (self-hosted or sudo on a VM with CONFIG_UPROBE_EVENTS) that runs LinuxTracingIntegrationTests without -E IntegrationTest.
  • Replace CheckIsStadiaInstance with “AMD GPU tracepoints exist” so GpuJobs can run on a desktop.
  • Add a test that user-space failure falls back to uprobes for those function ids.
  • Implement or delete OnThreadStateSliceCallstack coverage; set thread-state pid to the real pid.
  • Align CI with the README: Conan 2 or system packages, not both undocumented. Bump Actions to v4.
  • If cargo is missing, do not make LinuxTracing hard-link pyspy_ffi; stub the target.

P1 — design improvements (existing paths)

  • cgroup v2 cpuset. Teach GetCpusetCpus the unified hierarchy so fd count matches the quota. Memory tracks should read the same.
  • Watchdog vs cgroup memory.max. Half of host RAM is the wrong cap in Docker/k8s.
  • Per-function uprobe errors in the capture log, not one boolean.
  • Configurable reorder delay or flush-on-stop that drains below 333 ms once buffers are disabled.
  • Weighted poll. The TODO in Run is right: stack samples cost more than sched events.
  • Reuse or forbid. Make TracingHandler reset-able, or name it TracingSession and construct per capture (it already is constructed in DoCapture — the comment is leftover fear from an older lifetime).
  • Python: default off unless the user checks a box; detect via /proc/pid/maps for libpython, not the exe name. Add a unit test with a fake FFI.

P3 — hygiene

  • Gate PrintInstanceVersions cloudcast reads on the files existing, or drop them. Same for minidump path — use a flag.
  • Move GGP binaries behind WITH_GGP (default off) or delete if unused.
  • Strip copybara comments from the public fork, or keep them only if Google sync is still happening.
  • Fix building_arm64.md wording (uprobes ≠ trampolines).
  • Replace DoZoom global; peel a CaptureController out of OrbitApp as the existing comment asks.
  • Producer socket under /run/orbit/ with explicit mode, not world-visible /tmp.

Suggested order of work

  1. Tracefs fallback + sysfs probes that cannot throw (days of work, high leverage).
  2. Finish and merge the tracefs-once uprobe registration; run the bench on a real machine; paste numbers into the existing HTML report on that branch.
  3. One privileged CI job or a documented nightly for integration tests.
  4. cgroup v2 + watchdog that understands containers (Raspberry Pi / Docker users are already in this fork’s README).
  5. Python as an opt-in track, FFI stub when Cargo is absent.
  6. Then features (mid-capture hooks, non-AMD GPU, API frame tracks).
What not to do first. A Windows rewrite, a new capture-file version, or a track-hierarchy refactor will not make Hook/Stop trustworthy on Linux. The collector’s kernel contract is the product.
