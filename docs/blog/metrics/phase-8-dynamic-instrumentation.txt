  Its PT_LOAD segments, so the vaddr-to-file-offset arithmetic is checkable:
  LOAD           0x000000 0x0000000000000000 0x0000000000000000 0x000710 0x000710 R   0x1000
  LOAD           0x001000 0x0000000000001000 0x0000000000001000 0x00025d 0x00025d R E 0x1000

  The executable segment has p_offset == p_vaddr here, so both functions'
  file offsets equal their symbol addresses (0x11c0 and 0x11fb). That is the
  easy case; file_offset_of exists for the ones where it is not.

  Probes firing. perf_uprobe_event_init in the kernel requires CAP_PERFMON

  ENODEV or EINVAL, which establishes that the attr reached the uprobe PMU.
