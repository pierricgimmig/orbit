Orbit

A profiler for native applications: scheduling, callstack sampling, manual and dynamic instrumentation, on a timeline that draws a million scopes at the screen's refresh rate. The service is one static binary; the viewer is this page.

Below: a real capture, {{facts}}. Nothing is running behind it. Drag to pan, wheel over the ruler to zoom, click a thread to focus it, right-click a scope, press Home to fit.

Run it

orbit-service --serve 44766 serves this viewer and the API on one port; the banner prints the LAN address. Sampling needs perf_event_paranoid at -1 or CAP_PERFMON.
